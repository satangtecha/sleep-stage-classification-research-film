# การจำแนกระยะการนอนหลับจาก EEG ช่องเดียว


### สไลด์ที่ 1 ปัญหาและแนวคิดหลัก

“สวัสดีครับ งานที่ผมสนใจคือการจำแนกระยะการนอนหลับโดยอัตโนมัติจากสัญญาณ EEG

โดยทั่วไป การนอนหลับสามารถแบ่งออกเป็น 5 ระยะ ได้แก่ Wake, N1, N2, N3 และ REM ปัจจุบันการจำแนกระยะการนอนมักอาศัยผู้เชี่ยวชาญที่ตรวจสอบข้อมูลจาก polysomnography ซึ่งมีความแม่นยำ แต่ใช้เวลา ต้องใช้อุปกรณ์หลายชนิด และขยายไปใช้กับผู้ใช้จำนวนมากได้ยาก

แนวคิดของงานนี้คือการศึกษาว่า EEG เพียงหนึ่งช่องสามารถให้ข้อมูลเพียงพอสำหรับจำแนกระยะการนอนได้หรือไม่ โดยใช้โมเดล deep learnin

### สไลด์ที่ 2  แนวคิดและวัตถุประสงค์

“แนวคิดหลักค่อนข้างตรงไปตรงมา คือรับสัญญาณ EEG ช่องเดียวที่มีความยาว 30 วินาที เรียนรู้รูปแบบของสัญญาณทั้งในด้านเวลาและความถี่ แล้วทำนายว่า epoch นั้นอยู่ในระยะการนอนใดจากทั้งหมด 5 ระยะ

วัตถุประสงค์หลักคือพัฒนาและประเมิน pipeline สำหรับ sleep stage classification โดยอ้างอิงแนวทางจากงานวิจัยล่าสุด โมเดลจะประกอบด้วย synchrosqueezed time-frequency representation, convolutional neural network, contrastive learning และ GRU สองชั้น

งานนี้เป็น research prototype สำหรับการทดสอบ algorithm 

### สไลด์ที่ 3 — ขั้นตอนการทำงานของโมเดล

“ขั้นตอนการทำงานมีหลายส่วน

ขั้นแรก ผมจะดึงสัญญาณ EEG ช่อง Fpz-Cz และแบ่งข้อมูลออกเป็น epoch ละ 30 วินาที จากนั้นจะทำ normalization และแปลงสัญญาณเป็น time-frequency representation ด้วย synchrosqueezed transform

ต่อมา CNN จะเรียนรู้รูปแบบเฉพาะที่เกิดขึ้นในช่วงสั้น ๆ ของสัญญาณ ส่วน contrastive learning จะช่วยทำให้ feature ที่เรียนรู้มีความ robust ต่อ noise และการเปลี่ยนแปลงเล็กน้อยของสัญญาณ

สุดท้าย GRU สองชั้นจะประมวลผล feature windows ตามลำดับภายใน epoch แล้วส่งผลลัพธ์ออกมาเป็น Wake, N1, N2, N3 หรือ REM

ตัวชี้วัดหลักจะไม่ดูแค่ accuracy แต่จะใช้ macro-F1 และ F1 แยกแต่ละ stage ด้วย เพราะข้อมูลแต่ละระยะมีจำนวนไม่เท่ากัน และระยะ N1 กับ REM มักจำแนกได้ยากกว่า”

### สไลด์ที่ 4 — Dataset การประเมินผล และผลลัพธ์ที่คาดหวัง

“Dataset หลักที่จะใช้คือ Sleep-EDF Expanded ซึ่งเป็นชุดข้อมูลสาธารณะที่มีข้อมูล polysomnography ตลอดคืน พร้อม EEG และ hypnogram ที่ผู้เชี่ยวชาญให้ label

ตอนนี้ผมได้เตรียม pipeline เบื้องต้นและดาวน์โหลดข้อมูลบางส่วนเพื่อทดสอบระบบแล้ว ขั้นตอนต่อไปคือการขยายข้อมูลให้มากขึ้น และแบ่งข้อมูลในระดับ subject เพื่อไม่ให้ข้อมูลจากบุคคลเดียวกันปรากฏทั้งในชุด train และ test

การทดลองจะเปรียบเทียบ CNN baseline กับโมเดลเต็ม ทดสอบผลของ SST, contrastive learning, GRU และ class weighting โดยจะรายงาน accuracy, macro-F1, Cohen’s kappa, confusion matrix และผลแยกตาม sleep stage

ผลลัพธ์ที่คาดหวังคือ pipeline สำหรับจำแนก sleep stage จาก EEG ช่องเดียวที่ทำซ้ำได้ พร้อมการวิเคราะห์ว่าองค์ประกอบใดของโมเดลช่วยเพิ่มประสิทธิภาพ และโมเดลสามารถ generalize ไปยังบุคคลที่ไม่เคยเห็นระหว่างการ train ได้มากน้อยเพียงใด”
