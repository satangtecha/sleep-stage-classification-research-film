# วิธีใช้บน Overleaf

1. อัปโหลด `main.tex` และโฟลเดอร์ `fonts` เข้าโครงการ Overleaf โดยคงโครงสร้างเดิม
2. เปิด `Menu` แล้วตั้ง `Compiler` เป็น `XeLaTeX`
3. ตั้ง `Main document` เป็น `main.tex`
4. กด `Recompile`

ต้นฉบับใช้ฟอนต์ Sarabun ที่แนบไว้ในโฟลเดอร์ `fonts` จึงไม่ต้องติดตั้งฟอนต์เพิ่มบน Overleaf

หัวข้อ 4 ประกอบด้วยวิธีดำเนินการวิจัย 10 ส่วน และตารางแผนดำเนินงาน 12 เดือนที่วาดด้วย TikZ หากต้องการเปลี่ยนช่วงเวลา ให้แก้คำสั่ง `\schedulearrow{แถว}{เดือนเริ่ม}{เดือนสิ้นสุด}` ใน `main.tex`
